# Документація проєкту

Основна мова документації — англійська. Цей індекс містить додаткову
українську версію для розробника. [Англійський індекс](../en/README.md).

## Загальнопроєктна документація

- [Backend-тестування у Windows](backend_testing.md) — локальні PostgreSQL і Redis,
  ізольовані тестові Django settings, конфігурація PyCharm, команди тестування
  та межі захисту від зовнішніх викликів.
- [Схема бази даних](../db_schema.svg) — структура бази даних проєкту.

## Core

- [Розгортання спільного rate limiting](core/rate_limiting_deployment.md) — джерело
  IP клієнта, вимоги до public/private ingress Render, спільний Redis rate
  limiting, обробка HTTP 503 та вимоги до перевірки deployment.

## Main

- [Алгоритми views](main/views.md) — обробка запитів, завантаження даних,
  валідація та rate limiting контактної форми, постановка Celery-задач і відповіді.

## User

- [Алгоритми views](user/views.md) — реєстрація працівника, authentication,
  verification, password reset, межі транзакцій та CAPTCHA rate limiting.

## Додавання документації

Документацію додатків зберігайте за шляхом
`docs/<language>/<django_application>/<document>.md`.
Загальнопроєктні документи залишайте на верхньому рівні мовної директорії.
Нові документи додавайте до відповідних мовних індексів, а не окремими
посиланнями до головного README проєкту.
